# 二手闲置物品交易微信小程序

## 项目介绍

这是一个功能完整的二手闲置物品交易平台微信小程序，包含用户端小程序和管理后台系统。

### 功能模块

#### 1. 发布管理功能
- 支持拍照/相册上传商品图片
- 填写商品标题、详细描述、价格
- 选择商品分类和所在位置
- 一键发布功能
- 已发布商品可擦亮提高曝光
- 卖出的商品自动下架
- 支持手动上下架管理

#### 2. 浏览和搜索功能
- 首页分类导航
- 按照分类筛选商品
- 价格区间筛选
- 距离排序（就近推荐）
- 最新发布排序
- 关键词搜索商品
- 搜索历史记录

#### 3. 沟通和交易功能
- 内置即时聊天功能
- 买家卖家可在线沟通
- 可直接下单购买
- 资金由平台托管
- 确认收货后款项转入卖家账户
- 物流信息跟踪

#### 4. 订单和个人中心
- 我买到的订单
- 我卖出的订单
- 订单状态跟踪（待发货/待收货/已完成）
- 个人资料管理
- 发布记录管理
- 收货地址管理
- 账户余额查看

#### 5. 管理后台系统
- 数据概览仪表盘
- 用户管理（启用/禁用/删除）
- 订单管理（查看/删除/详情）
- 商品管理（上下架/删除/详情）
- 分类管理（新增/编辑/删除）
- 系统配置（基本配置/交易配置/其他配置）

## 使用说明

1. 将 `miniprogram` 目录导入微信开发者工具
2. 配置小程序 AppID（测试可使用测试号）
3. 在开发者工具中运行即可预览效果

## 功能演示

### 小程序主要页面
1. **首页** - 浏览商品、分类筛选、搜索
2. **发布** - 上传图片、填写信息发布商品
3. **消息** - 查看聊天列表、沟通交易
4. **我的** - 个人中心、订单管理、地址管理

### 管理后台主要功能
1. **数据概览** - 用户/订单/商品统计数据
2. **用户管理** - 用户列表、状态管理
3. **订单管理** - 订单查询、详情查看
4. **商品管理** - 商品审核、上下架管理
5. **分类管理** - 商品分类配置
6. **系统配置** - 平台参数设置

## 注意事项

1. 当前版本使用Mock数据，不连接真实服务器
2. 聊天功能为模拟实现，真实场景需要WebSocket支持
3. 支付功能需要对接微信支付接口
4. 文件上传需要配置真实的上传接口

## 开发建议

### 接入真实后端需要修改的部分

1. `miniprogram/utils/api.js` - 替换Mock接口为真实API
2. `miniprogram/app.js` - 修改登录逻辑
3. `admin/js/api.js` - 替换后台接口为真实API

### 需要对接的第三方服务

1. 微信登录API
2. 微信支付API
3. 文件存储服务（如阿里云OSS、腾讯云COS）
4. 即时通讯服务（WebSocket）
5. 地图定位服务
